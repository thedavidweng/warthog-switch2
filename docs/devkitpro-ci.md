# devkitPro in Switch 2 CI

The Switch 2 job in [Build run 45941319344](https://github.com/thedavidweng/warthog-switch2/actions/runs/45941319344/job/140316133498) pulled the devkitPro base image, then failed when `dkp-pacman -Sy` fetched `dkp-linux.db` and `dkp-libs.db` from `pkg.devkitpro.org`. Both requests returned HTTP 403. A devkitPro maintainer confirmed that they block GitHub CI traffic because repeatedly installing entire toolchains strains their package bandwidth. Their guidance for CI is to use the devkitPro images on Docker Hub. [Maintainer explanation](https://github.com/devkitPro/installer/issues/69#issuecomment-3875396643) · [Pacman release guidance](https://github.com/devkitPro/pacman/releases/tag/v6.0.2)

The official `devkitpro/devkita64` image pinned in [UPSTREAM.json](../UPSTREAM.json) is available for both Linux architectures used by the project, amd64 and arm64. A local `dkp-pacman -Q` in the arm64 image confirmed it already includes `switch-tools`, `switch-pkg-config`, `dkp-toolchain-vars`, `switch-sdl2`, `switch-curl`, `switch-mbedtls`, `switch-zlib` and `switch-bzip2`. The Warthog image checks these against the local package database, installs exact ouncebrew package URLs with signature verification, and removes the inherited devkitPro APT source before installing Debian and LLVM tools. [Official devkitA64 image](https://hub.docker.com/r/devkitpro/devkita64)

ouncebrew documents building the ounce-devkit Dockerfile locally. The pinned recipe starts from devkitPro’s Switch image and runs `install.sh`, which refreshes pacman repositories. Public GitHub Packages listings, Docker Hub, and ounce-devkit’s release assets did not expose a ready-to-pull ounce-devkit image. The releases provide historical archives, and the maintained components publish individual pacman packages. Warthog’s image also builds its pinned Drako3D and UAM2 tooling. [Pinned ounce-devkit README](https://github.com/ouncebrew/ounce-devkit/blob/5e957599bd498643d82e5470aec80da67a12685d/README.md) · [Pinned Dockerfile](https://github.com/ouncebrew/ounce-devkit/blob/5e957599bd498643d82e5470aec80da67a12685d/Dockerfile) · [Pinned installer](https://github.com/ouncebrew/ounce-devkit/blob/5e957599bd498643d82e5470aec80da67a12685d/install.sh) · [Releases](https://github.com/ouncebrew/ounce-devkit/releases) · [Warthog Dockerfile](../scripts/switch2/Dockerfile)

A later ounce-devkit change upgrades devkitA64 to match the shared `libstdc++.so.6` shipped with libounce. That update also uses pacman to refresh devkitPro. Verify Warthog’s own link and NRO build against the pinned compiler when using the prebuilt base. [ounce-devkit compiler update](https://github.com/ouncebrew/ounce-devkit/commit/7afad67b2169078d44834f95fcd7aa233b4f7b5d)
